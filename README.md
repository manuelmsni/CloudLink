# ☁️ CloudLink
[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen?style=for-the-badge&logo=google-chrome&logoColor=white)](https://manuelmsni.github.io/CloudLink/)

CloudLink es un lanzador de aplicaciones minimalista que utiliza **Google Drive** como gestor de acceso a apps.
Permite a los usuarios autenticarse y acceder dinámicamente a módulos de software alojados de forma privada.
